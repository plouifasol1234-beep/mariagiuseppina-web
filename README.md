```bash
pip install -r requirements.txt
streamlit run app.py
```

- Fotos: a `img/` (`hero`, `tupper`, `davantal`, `plats`, `retrat`, `card1`…`card5`, en jpg/png/webp).
- Contacte: edita `WHATSAPP` i `EMAIL` a l'inici d'`app.py`.
